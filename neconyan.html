Neconyan

v1.2.5 · The Cutest LLM RP Frontend™

My own fork of SillyTavern and SillyBunny, with its own interface, defaults and direction. Character chats, notes, writing tools and model settings all live in one cat-themed workspace that works on a phone as well as it does on a desktop. You bring the model, either a local backend or an API key - no model access or credits come with it.

I run it on a small server and use it mostly from my phone, so phones aren't a squashed desktop here. Almost everything runs on the server now, so you can send a message, switch apps or lock the screen, and the reply's sitting there when you come back. A few things still need the page open, like in-browser WebLLM models and Kokoro voices.

It reads the same character cards, chats, lorebooks, personas and presets as SillyTavern, so bringing your stuff over is a starting point rather than a rebuild. I only pull in the upstream bits I want though, so some things look and behave differently, and extensions that depend on SillyTavern's page layout might not work. If you want SillyTavern with everything working exactly like upstream, use SillyBunny instead.

  • Four ways to chat: Roleplay, Conversation, Meower and Story Mode.
  • Notebooks for character drafts, places, scene plans and session journals, right next to your chats.
  • Scratchpad, a side chat with Miso, Taro or Nori for planning a scene or checking continuity. Nothing you write there ends up in the story.
  • Pura's Director Preset 16.0 and The Ethereality Express 1.1 come bundled as the default presets. The trackers and randomisers ship as agents instead of preset toggles.
  • The Android app runs the whole thing on the phone itself, so no Termux and no computer. It needs Android 11 or newer on a 64-bit ARM phone, Android System WebView 124 or newer, and about 2 GiB free.
  • On a computer it runs on Bun or Node.js, with launchers for Windows, macOS, Linux and Termux. Clone it with Git and the launcher updates itself every time you start it. Default address is http://127.0.0.1:4433/.

What's Different

The stuff I actually wanted out of a frontend

It Keeps Going When You Leave
Replies, agents and most background work run on the server, not in the tab. Send a message on your phone, lock the screen, and it's done when you come back. Phone browsers kill tabs constantly, so this was the first thing I fixed.
Phones Come First
Labelled tab rows instead of dropdowns, a slim bottom chat bar, a sliding menu and a sign-in that can remember your device for 30 days. Anything you can reach on a desktop you can reach on a phone, and there's no simple/advanced switch hiding half the settings from you.
Four Modes
Roleplay is the classic chat, with a cat asleep on your messages. Conversation is texting your characters like a friend, with a Pals list, group chats, branches and characters who can be busy or offline. Meower is a tiny social timeline where your cast posts, replies to each other and runs polls about snacks. Story Mode turns the chat into continuous prose.
Notebooks
Somewhere for the character drafts and scene plans you'd otherwise lose in a text file. Templates, folders, properties, a read view, and links between notes and to your lorebooks. You can open it beside a chat, and the assistants can edit notes if you let them.
Scratchpad
A side chat with Miso, Taro or Nori that never touches the story. Ask them to read the scene, pitch plot ideas, catch you up, check continuity or find lore gaps. Round table asks up to three at once, each on their own connection, and Ask Scratchpad from a note shares just that note.
Mewmory
Story memory that keeps track of what happened, the NPCs you've met and what they said, so you're not re-explaining everything 200 messages later. It can run on a cheaper model than the one writing your replies, and you can look through it, correct it or undo it when it gets something wrong.
Assistants and a Tour
Miso, Taro and Nori each come in male, female and neutral versions. They can use tool calls to make characters with portraits, edit lorebooks and adjust presets, and since 1.1.1 they can build agents for you too. The short First paws tour walks you through the basics, and you can hide it.
Chat Links
Copy a link to an exact saved chat, branch included, and bookmark it. Optionally keep the address bar on the chat you're viewing, or reopen your last chat on launch. Both are off by default.
It's Cute
Calico themes, cats napping on your messages and a pixel cat on Home. That was the whole point, really. There are also AMOLED Black, Windows 98 and Windows Aero themes if you'd rather not, and every bundled theme is checked for readable contrast.
Your Data Stays Yours
Same file formats as SillyTavern for characters, chats, lorebooks, personas and presets, and no telemetry. Back up your old install and use a separate data folder when you move over.

Agent Stack

Small models doing the boring work so the good one can write

In-Chat Agents
An agent is a stored prompt with its own conditions, stage, connection profile and output handling. Toggle them, group them, import and export them. Each one can run on a different model than your main chat, which is the part I use most - a cheap model doing tracker work while the expensive one writes prose.
The Pipeline
Agents can run before the reply to add rules or trackers, alongside it for commentary, or after it for a second pass over the finished text. The after-reply pass is where proofreading and prose polishing happen.
Companion Agents
Companions make their own model calls and store the results instead of touching your reply - that's how the tracker panels get filled in. They can run all at once or one at a time. Parallel if you're impatient like me, sequential if your provider starts complaining about rate limits.
Built From the Presets
Every bundled tracker agent uses the same prompt and regex as its toggle in Pura's Director Preset 16.0 (SillyTavern) or The Ethereality Express 1.1, so the cards look the same either way. That's why the Neconyan preset can stay lean.
Proofreader and Prose Polisher
Both come installed and switched off until you want them. They run after the reply and rewrite the finished text as a second pass, so the main model doesn't have to get everything right in one go.
Ask for One
If none of the bundled ones fit, describe what you want to Miso, Taro or Nori and they'll make the agent for you.
What Ships Right Now
Every Pura tracker and randomiser, the Ethereality Express trackers and Doors & Dice menus, formatting helpers, content toggles, preset groups, and companions like Expressions and Plot Compass.

What's New

Since 1.0. Full changelog on GitHub.

1.2.5

  • Reorganised Agents, with Quick settings on each card and shared edits for selected agents.
  • Added Character Authenticity Checker, an optional reply rewriter for keeping characters in character. It starts switched off.
  • Scratchpad can propose character cards from a discussion or notebook. You review the changes before saving.
  • Character Expressions supports separate sets for people sharing a card, named speakers, custom expression lists and better image cleanup.
  • Slash-command scripts can run during replies without losing your draft.
  • Rebuilt Formatting, kept Connections status compact and made Companion actions easier to reach on phones.
  • Added a dark Windows XP Olive theme and separate sleeping-cat choices for each side of the chat.
  • Android export fixes, smoother drawers, and more German, Italian and Portuguese translations.

1.2.0

  • Scratchpad and Notebooks talk to each other now. Ask Scratchpad from a note shares that note, or just the bit you selected.
  • Renaming a chat keeps its Scratchpad sessions.
  • Rebuilt the Persona page.
  • Note templates show which one you picked, and notes have a Delete button.
  • Tab accepts a Notebook link suggestion on list lines.
  • Chat Archive loads on big libraries instead of giving up.
  • The phone menu doesn't throw you back to Home anymore.
  • A lot more of the interface is in Portuguese.

1.1.1

  • Added Scratchpad, a side chat for planning stories with Miso, Taro and Nori.
  • Chat links, and an option to reopen your last chat on launch.
  • The assistants can make agents for you.
  • AMOLED Black theme.
  • Slimmer bottom chat bar, and more character cards fit on screen in the phone list.
  • Dismissed tour invitations stay dismissed after a reload.
  • Preset names don't get translated anymore, so picking, renaming and deleting presets works in every language.

1.1.0

  • Added Notebooks, with assistant edits and links to your lorebooks.
  • Windows 98, Windows Aero and Windows Aero Light themes.
  • Roleplay replies use your configured reply length, and a quoted context size can't block them anymore.
  • Italian and German translation fixes.
